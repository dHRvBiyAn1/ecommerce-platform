Phase 2 — Page Migrations: Zard → PrimeNG

Replace all Zard components with PrimeNG equivalents

Component Mapping

Zard Component PrimeNG Replacement
z-button <p-button>
z-input <input pInputText>
z-badge <p-badge>
z-card <p-card>
z-table <p-table>
z-dropdown-menu <p-menu> / <p-tieredMenu>
z-layout/header/content/footer Sakai custom layout (app-layout)
<z-toast> + ngx-sonner <p-toast> + MessageService
<z-sidebar> Sakai sidebar component

Public Pages (Home, Products, Cart, etc.)

Use Sakai overlay mode — sidebar collapsed by default, accessible via hamburger.
Topbar shows: logo, "Products" nav link, cart icon with p-badge, user dropdown.
Content area is full-width. No admin sidebar cluttering the storefront.

Admin/Seller Pages

Use Sakai static mode — fixed left sidebar (256px) visible at all times.
Topbar shows: hamburger (toggle sidebar), logo, page title, user avatar dropdown.

Toast System

Replace ngx-sonner with PrimeNG's built-in <p-toast> component.
Inject MessageService for showing success/error/info toasts.
Update the auth interceptor and role guard accordingly.

Icon Migration

Replace <ng-icon name="lucideShoppingCart"> with <i class="pi pi-shopping-cart"></i>.
PrimeIcons are built-in with PrimeNG — no extra install or providers needed.
