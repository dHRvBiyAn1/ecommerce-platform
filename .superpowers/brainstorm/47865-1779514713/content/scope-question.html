Migration Scope Question

Sakai is an admin template — how should we handle the public storefront pages?

Current Pages (30 files use Zard UI)

🏪 Home 🔐 Login 📝 Register 📦 Products 🔍 Product Details 🛒 Cart 💳 Checkout ✅ Order Success 👤 My Account 📊 Seller Dashboard 📋 Inventory ➕ Add Product 👑 Admin Users
A

Sakai for Admin/Seller + Storefront

Use Sakai's full layout (topbar + sidebar + footer) for admin, seller pages. Use PrimeNG components + Tailwind for the public storefront pages (Home, Products, Cart, etc.) with a simple header/footer.

B

Sakai Layout EVERYTHING

Use the Sakai layout wrapper (app-layout) for ALL pages — the sidebar is collapsed or hidden on public pages. Every page uses the same template shell.

C

Sakai Admin Only — Simple PrimeNG for Public

Sakai layout for admin + seller pages only. Public pages use lightweight PrimeNG components with a custom minimal layout (no sidebar). This keeps the public site fast and the admin area feature-rich.

My recommendation

Keeps public storefront clean, admin area gets full Sakai layout. Matches SAKAI's intended use case.
