Phase 1 — Foundation: PrimeNG + Sakai Layout

Install PrimeNG stack, remove Zard, create Sakai layout shell

1. Install PrimeNG Dependencies

Replace Zard UI stack with PrimeNG ecosystem:

npm install primeng primeicons @primeuix/themes @tailwindcss/postcss tailwindcss-primeui

Remove Zard UI (shared/components/*) and unused deps: class-variance-authority, clsx, tailwind-merge, ngx-sonner, embla-carousel*

2. PrimeNG Config (app.config.ts)

import Aura from '@primeuix/themes/aura'; import { providePrimeNG } from 'primeng/config'; providers: [ providePrimeNG({ theme: { preset: Aura, options: { darkModeSelector: '.app-dark' } } }) ]

3. Sakai Layout Structure

Mirror Sakai's component tree but adapted for our e-commerce routes:

app-layout (wrapper for ALL pages) ├── app-topbar — logo, nav links, cart badge, user dropdown ├── app-sidebar — collapsible sidebar with menu items │ ├── Dashboard │ ├── Products │ ├── Orders │ └── ...role-based items ├── router-outlet (page content) └── app-footer

4. Sidebar Behavior

Sakai has 2 menu modes: static (fixed sidebar) and overlay (sidebar overlays content).
We'll use overlay on public pages (sidebar hidden by default, hamburger to show) and static on admin/seller.

5. Remove Zard Completely

  • Delete src/app/shared/components/ (45 component dirs)
  • Remove provideZard() from app.config.ts
  • Remove all <z-*> component references
  • Update styles.css — replace Zard CSS variables with PrimeUI theme tokens

6. Icon Strategy

Replace @ng-icons/lucide with PrimeIcons (built-in, tree-shakable).
Use <i class="pi pi-shopping-cart"></i> syntax.
